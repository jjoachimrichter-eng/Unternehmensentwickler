# BusinessDeveloper Website

Responsive One-Page-Website für Business Development und Unternehmensstabilisierung.

## Vor Veröffentlichung anpassen

1. In `index.html` die Adresse `IHRE-EMAIL@BEISPIEL.DE` ersetzen.
2. `impressum.html` vollständig ausfüllen.
3. `datenschutz.html` an Betreiber, Hosting und Dienste anpassen.
4. Optional Google Fonts lokal einbinden.

## GitHub Pages

In den Repository-Einstellungen unter **Pages** als Quelle **Deploy from a branch**, Branch `main`, Ordner `/ (root)` wählen.
